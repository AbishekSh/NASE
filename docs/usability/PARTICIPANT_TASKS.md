# NASE Participant Tasks

## Instructions

Complete each goal as you naturally would. Please say what you are looking for,
what you expect controls to do, and anything that surprises you.

You are testing the interface, not your computer skills. You may stop a task at
any time.

---

## Task 1: Understand the App

Open NASE and spend up to two minutes looking around.

When you are ready, explain:

- what you think NASE does;
- what you would do first;
- where you think your games and applications will appear.

Do not start installing anything yet.

---

## Task 2: Add a Windows App

The moderator will give you a Windows application file.

Add it to NASE so that you could find and open it again later.

Stop when you believe the application is part of your NASE library.

---

## Task 3: Install a Windows App

The moderator will give you an installer for a Windows application.

Use NASE to install the application. When installation is finished, make the
installed application—not just its installer—available from your NASE library.

Stop when you believe you could close NASE, reopen it, and launch the installed
application without running the installer again.

---

## Task 4: Launch and Close an App

Launch the Windows application you added.

Use it briefly, then close it in the way that feels most natural. Confirm for
yourself that NASE understands the application is no longer running.

Stop when you believe it is safe to launch the application again.

---

## Task 5: Set Up Steam

Imagine that you installed NASE because you want to play a Windows Steam game.

Set up what you think is required and reach the point where you could sign in
to Steam. Do not enter a personal password while the session is being recorded.

Stop when you believe NASE is ready for Steam.

---

## Task 6: Find and Launch a Steam Game

Find the game named by the moderator and launch it through NASE.

After it opens, return to NASE and explain what state you think the game is in.
Close the game normally and decide when it is safe to reopen.

---

## Task 7: Try a Different Compatibility Option

Imagine a game opens but has visual glitches. You want to try a different
graphics or compatibility option for only that game.

Make the change you think is appropriate and launch the game again.

Stop when you believe the new option was used without reinstalling the game.

---

## Task 8: Recover From a Stuck App

Imagine you closed a Windows app, but NASE still appears to think it is
launching or running.

Find a way to recover and make it safe to launch again. Try to avoid stopping
unrelated applications if the interface offers a more focused option.

Stop when you believe the stuck state is cleared.

---

## Task 9: Find Help for a Failure

Imagine a game failed to open and you want enough information to ask for help.

Find what you would inspect or share with the NASE developers. Explain what you
would include in a bug report and what private information you would avoid
sharing.

You do not need to submit a real report.

---

## Task 10: Remove an Unused Compatibility Profile

Imagine you tried an alternate compatibility option and no longer want the
extra installation. Remove the unused profile while keeping the shared game
installed.

Before confirming anything, explain what you believe will be deleted.

---

## Task 11: Uninstall NASE

Imagine you are finished evaluating NASE.

Find how to uninstall it. Before confirming, explain:

- what will happen to NASE itself;
- what managed data will be removed;
- what can be kept for a future reinstall;
- whether imported files or external game libraries will be affected.

Do not complete the uninstall unless the moderator asks you to.
